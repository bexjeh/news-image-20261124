Sum up 24 November's world news in one image — a world-atlas infographic of
five verified stories from Tuesday 24 November 2026: the World Chess
Championship opening in Geneva, Portugal's 2027 budget vote in Lisbon,
Germany's Ifo business survey, the first Ayodhya–Janakpur train reaching
Nepal, and the Beaver Supermoon beside the Pleiades. A stylised world map
with numbered story pins, a date banner, and a legend panel; every headline
was checked against its source for the 24 November date.

## Run it

```sh
python3 main.py
```

The program copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or the
current directory when unset). It is deterministic: the same bytes on every
run, no network, no randomness.
